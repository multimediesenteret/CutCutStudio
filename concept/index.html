Prøv flyten
  1. Trykk «Demo: simuler kortskanning» på touch-skjermen.
  2. Velg hvem som er med, og trykk Start opptak.
  3. Se teknikervinduet klippe, med regel-ID for hvert kutt.
  4. Hold «Avslutt opptak» inne i 2 sekunder.
Brukeren tenker ikke på teknikkKort, ett valg av personer, eventuelt kun lyd, og Start. Standardvalgene er klare, så det holder å skanne og trykke Start.
Teknikeren ser alt på én sideMultiview, program og preview, mikrofoner, beslutninger og tidslinje. Oppsett, helse og kameraer ligger i menyen til venstre.
Feil og hjelpUnder Helse kan du simulere feil. Rødt på lyd stopper Start på touch med en enkel melding. «Trenger du hjelp?» varsler teknikeren.

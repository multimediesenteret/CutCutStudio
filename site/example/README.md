# site/example

Fiktivt studio for simulatoren og testene (C-8). Ingen ekte navn, IP-er eller kortnummer. Følger samme oppsett som NTNU-studioet slik konseptet antar (Q26): CAM 1 = programleder, CAM 2–4 = gjester, CAM 5 = fugleperspektiv, IN 6 = laptop.

| Fil | Innhold |
| --- | --- |
| `devices.yaml` | Utstyr og adresser (IP-plan fra spesifikasjonen 2.6) |
| `staff.yaml` | Fiktive teknikere (`operator`) og administratorer (`admin`) |
| `shows/*.yaml` | Show-oppsett for 1, 2, 3 og 4 deltakere |
| `equipment/companion_map.yaml` | Knappene på Companion side 10 (spesifikasjonen 7.1) |

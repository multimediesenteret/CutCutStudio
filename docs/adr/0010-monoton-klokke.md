# ADR-0010: Monoton klokke i motoren, NTP for veggklokke

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Tidsregler påvirkes ikke av at klokka justeres.

## Beslutning

Monoton klokke i motoren, NTP for veggklokke.

## Konsekvenser

Alle tidsregler testes med falsk klokke.

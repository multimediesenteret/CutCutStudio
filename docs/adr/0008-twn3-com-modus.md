# ADR-0008: Kortleser (ELATEC TWN3) i virtuell COM-port-modus, ikke som tastatur

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Virker uten tastaturfokus og gir pålitelig kortnummer.

## Beslutning

Kortleser (ELATEC TWN3) i virtuell COM-port-modus, ikke som tastatur.

## Konsekvenser

Leseren konfigureres med TWNConfig; format avklares i Q4.

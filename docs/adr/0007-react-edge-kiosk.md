# ADR-0007: Grensesnitt i React + TypeScript, servert lokalt; touch-skjermen i Edge kiosk-modus med tilordnet tilgang

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Brukeren kan ikke gå ut av appen; samme kode for begge skjermer.

## Beslutning

Grensesnitt i React + TypeScript, servert lokalt; touch-skjermen i Edge kiosk-modus med tilordnet tilgang.

## Konsekvenser

Avhenger av Q8 (om PC-en er sentralt administrert).

# ADR-0011: Brytere kan endres i sanntid fra teknikervinduet

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Nye funksjoner kan prøves uten ny versjon.

## Beslutning

Brytere kan endres i sanntid fra teknikervinduet.

## Konsekvenser

Hver endring logges i revisjonsloggen.

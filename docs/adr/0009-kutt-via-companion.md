# ADR-0009: Kutt og layouter går via Companion; ATEM leses direkte

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Stream Deck og motor bruker de samme knappene.

## Beslutning

Kutt og layouter går via Companion; ATEM leses direkte.

## Konsekvenser

Direkte ATEM-kutt finnes bare som reserve når Companion er nede.

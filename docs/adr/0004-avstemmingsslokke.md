# ADR-0004: Avstemmingssløyfe: hvert sekund sammenlignes ønsket og faktisk tilstand for ATEM, Pearl og kameraer

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Tåler tapte kommandoer og manuelle inngrep uten å «slåss» mot operatøren (I5).

## Beslutning

Avstemmingssløyfe: hvert sekund sammenlignes ønsket og faktisk tilstand for ATEM, Pearl og kameraer.

## Konsekvenser

Avvik logges; motoren tilpasser seg det den leser tilbake.

# ADR-0001: Én Windows 11-PC kjører alt: motor, Companion, touch-skjerm og teknikervindu

- **Status:** Akseptert
- **Dato:** 2026-10-20
- **Kilde:** spesifikasjonen 0.3

## Kontekst

Én maskin å drifte; brukeren har én skjerm å forholde seg til.

## Beslutning

Én Windows 11-PC kjører alt: motor, Companion, touch-skjerm og teknikervindu.

## Konsekvenser

Ingen redundant maskin. I1 sikrer at ATEM og Pearl fortsetter alene hvis PC-en stopper.
